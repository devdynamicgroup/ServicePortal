# M9.1 — Care Operations Cadence

**Status:** Active after Care SEND (and useful during dry-run)  
**Related:** `docs/M9.1_CARE_RUNBOOK.md` · `docs/M9.1_ROLLBACK_CARD.md` · `docs/M9.4_CARE_PRODUCTION_RUNBOOK.md` (Phase 3+ ladder) · `docs/M9.5_CARE_STEADY_STATE_HANDBOOK.md` (Phase 4+ steady state)

---

## Weekly

- [ ] `node scripts/check-care-rollout-gates.js`
- [ ] `node scripts/check-care-steady-state.js` (governance reminders; Phase 4+)
- [ ] `node scripts/check-care-production-readiness.js` (when approaching or after SEND)
- [ ] Review latest `tmp/care-lifecycle/latest.json` counts (`dryRun` / `sent` / `skipped` / `failed`)
- [ ] `node scripts/run-care-outcome-report.js` + review `latest-outcome-report.json`
- [ ] `node scripts/check-care-patterns.js` (advisory warnings only)
- [ ] Follow `docs/M9.3_POLICY_REVIEW_RUNBOOK.md` classification
- [ ] If policy change proposed: draft CDR per `docs/M9.3_CARE_DECISION_RECORDS.md` (human approve before apply)
- [ ] Spot-check skip reason mix
- [ ] Spot-check any `failed` rows + LINE errors
- [ ] Confirm Case result-send health unchanged
- [ ] If SEND on: confirm cron still single-runner; idempotency skips look sane; fail-pause (≥20%, n≥5) not breached

Optional during Phase 2:

```bash
node scripts/run-care-lifecycle.js scan --event=reinspection_6mo --mode=dry-run
```

---

## Monthly

- [ ] Eligible volume trend vs Case population  
- [ ] Care copy / tone still appropriate  
- [ ] Consent skip samples (`consent_line_false`)  
- [ ] Confirm no pressure to remove Case LINE or merge Care into Case notification state  
- [ ] On-call still knows rollback card (`docs/M9.4_CARE_ROLLBACK_CARD.md` / M9.1)  
- [ ] M9.3 effectiveness pass — `docs/M9.3_EFFECTIVENESS_GOVERNANCE.md` + open CDRs follow-up  

---

## Per deploy

- [ ] CARE flags match intended phase  
- [ ] `node scripts/test-care-lifecycle.js` in CI/staging when care code changes  
- [ ] `node scripts/test-care-governance.js` when governance docs/scripts change  
- [ ] `node scripts/test-care-steady-state.js` when M9.5 package changes  
- [ ] Gate script warning review  

---

## Incident

1. **Rollback first** — `docs/M9.4_CARE_ROLLBACK_CARD.md` (or `docs/M9.1_ROLLBACK_CARD.md`)  
2. **Investigate second** — Care Audit, LINE logs, eligibility sample  
3. Re-enter Phase 2/3 only after go/no-go  
4. Optional post-incident CDR (do not rewrite historical audits)
