# M8.2 — Validation Report Design

**Status:** Architecture design (not implemented)  
**Requirement:** Every dry-run and write run emits this report (JSON and/or CSV). Observable and auditable.

---

## Report metadata

| Field | Description |
|-------|-------------|
| `runId` | Unique run identifier |
| `mode` | `dry-run` \| `write` |
| `startedAt` / `finishedAt` | ISO timestamps |
| `operator` | Who triggered (if known) |
| `gitSha` / `appVersion` | Optional environment marker |
| `flagsSnapshot` | Must show all Customer Domain flags OFF |

---

## Counters

| Field | Meaning |
|-------|---------|
| `casesScanned` | Total Case pages examined |
| `casesEligible` | Had enough identity to consider |
| `casesSkippedNoIdentity` | No name and no strong key |
| `casesAlreadyLinked` | Case already had Customer ID |
| `casesLinked` | Cases newly linked this run (write) or would-link (dry-run) |
| `customersCreated` | New Customer records (write) / would-create (dry-run) |
| `customersMatched` | Existing Customer reused by exact key |
| `customersUnverifiedCreated` | Name-only provisional Customers |
| `duplicateCandidates` | Same key maps to >1 existing Customer |
| `conflicts` | Divergent identity within a proposed group |
| `ambiguousMatches` | >1 possible Customer; no auto choice |
| `errors` | Hard failures (API, schema, unexpected) |

---

## Detail sections (arrays)

Each item should include Case `notionId` and enough identity for ops review (mask PII in shared logs if required).

| Section | When used |
|---------|-----------|
| `skipped[]` | No identity / invalid-only |
| `wouldCreate[]` / `created[]` | New Customer projection |
| `wouldMatch[]` / `matched[]` | Exact reuse |
| `duplicateCandidates[]` | Key + conflicting customerIds |
| `conflicts[]` | e.g. same phone, divergent email |
| `ambiguousMatches[]` | Multiple candidates; blocked |
| `errors[]` | message + case id |

---

## Pass / fail gates

| Gate | Dry-run | Write |
|------|---------|-------|
| Flags all OFF | Required | Required |
| Schema (Customers + Case link props) | Warn if missing | Required |
| `duplicateCandidates` unexplained | Review before write | Block re-run until resolved or acknowledged |
| Re-run idempotency | N/A | `customersCreated` for already-linked Cases must be 0 |
