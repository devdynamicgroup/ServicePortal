## Outcome schema (locked shape)

Persisted on / derived beside CareAuditEvent:

```json
{
  "careAuditId": "...",
  "deliveryStatus": "sent",
  "responseStatus": "no_response",
  "rebookWithin30d": false,
  "utmSource": null,
  "utmCampaign": null,
  "careAuditIdFromUtm": null,
  "linkedCaseIdAfter": null,
  "outcomeAt": null,
  "outcomeSource": null,
  "observationWindowEndsAt": "...",
  "measuredAt": "..."
}
```

### Field rules

| Field | Rule |
|-------|------|
| `deliveryStatus` | Mirror audit `status` (or map: sent→sent, failed→failed, skipped→skipped, dry_run→dry_run) |
| `responseStatus` | `unknown` \| `no_response` \| `utm_click` \| `rebooked` \| `opted_out` |
| `rebookWithin30d` | true if a later Case attributed within 30d |
| `utmSource` / campaign | From booking URL query when present (`utm_source`, `utm_campaign`, `care_audit_id`) |
| `observationWindowEndsAt` | `sentAt + 7d` (response window) |
| Never | Write any of these onto Case `notificationStatus` / `resultSentAt` |

### Rebook attribution

A later Case `B` attributes to care audit for Case `A` when **all** hold:

1. Audit `status === sent` and `sentAt` present  
2. `B.createdTime` (or Case create timestamp) ∈ `(sentAt, sentAt + 30d]`  
3. Exact match: `B.customer.id === audit.customerId` **or** (if both have LINE) `B.line.userId ===` original Case LINE for `A`  
4. `B.notionId !== A.notionId`  

First matching `B` wins → `linkedCaseIdAfter`, `responseStatus=rebooked`, `rebookWithin30d=true`.

### UTM (optional, non-blocking)

Booking / care CTA may append:

```text
?utm_source=care&utm_campaign=reinspection_6mo&care_audit_id=<auditId>
```

M9.2 **reads** attribution when booking payloads or Case source fields expose it; if not available yet, UTM fields stay null and rebook path still works. **Do not** require Framer contract break — additive query params only when Care templates are later updated (may be a thin template change in implement; plan allows deferring template UTM to keep SEND path untouched).

## Runtime flows

### Measure (offline)

```text
load care audits (events.jsonl / latest)
load Cases (optional, for rebook)
  → for each sent audit: evaluate rebook within 30d
  → set responseStatus / rebookWithin30d / linkedCaseIdAfter
  → if TRACKING: write outcome fields back to audit store
  → else: report-only in memory
```

### Report (read-only)

```text
node scripts/run-care-outcome-report.js
→ {
    delivery: { sent, failed, skipped, dry_run },
    response: { no_response, rebooked, utm_click, unknown },
    rebookRate,
    samples (PII-safe)
  }
```
