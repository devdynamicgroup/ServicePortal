# M8.9 — Operations Cadence (Customer Identity)

**Status:** Active ops checklist  
**Runtime impact:** None — operators run existing CLIs  
**Related:** `docs/M8.9_IDENTITY_GOVERNANCE.md` · `docs/M8.8_PHASE_RUNBOOK.md`

---

## Weekly (steady state — all environments with Customer DB)

- [ ] `node scripts/run-customer-reconcile.js scan`
- [ ] Confirm `gateResult` / triage failures
- [ ] Archive `tmp/customer-reconcile/reconcile-*.summary.json`
- [ ] `node scripts/run-customer-merge.js detect`
- [ ] Review ambiguity / merge queue tickets
- [ ] Drift review: orphans, `lineDiverge`, missing links
- [ ] Soft phone/email conflicts → steward backlog if needed
- [ ] `node scripts/check-customer-rollout-gates.js` (flags match intended phase)

### Suggested SLAs

| Finding | Response |
|---------|----------|
| Unticketed orphan link | ≤ 2 business days |
| Unticketed `lineDiverge` | ≤ 1 business day (ticket; no auto-repair) |
| Merge queue item | Steward ≤ 5 business days |

---

## Monthly

- [ ] Soft conflict backlog review with identity steward  
- [ ] Confirm Case LINE retention policy still understood (no cleanup tickets without ADR)  
- [ ] Spot-check dual-write health if `DUAL_WRITE` is ON  
- [ ] Confirm on-call still knows `docs/M8.8_ROLLBACK_CARD.md`  

---

## During M8.8 rollout (daily while in shadow / early primary)

Applies only while Phases 3–6 are in progress:

- [ ] `node scripts/dump-customer-line-read-metrics.js` (or log review `[customer_line_read]`)
- [ ] `node scripts/dump-customer-notify-read-metrics.js` (or `[customer_notify_read]`)
- [ ] Dual-write health: Case create / linkLineUser not blocked; error rate trending OK
- [ ] Mismatch / conflict / wrong-recipient review vs phase gates
- [ ] Update go/no-go checklist soak clocks (`docs/M8.8_GO_NO_GO_CHECKLIST.md`)

---

## Per deploy / restart

- [ ] `node scripts/check-customer-rollout-gates.js`
- [ ] Confirm env flags match intended phase (defaults OFF until consciously enabled)
- [ ] Note: in-process metrics reset on restart — prefer logs for durable windows

---

## Incident

1. **Rollback first** — `docs/M8.8_ROLLBACK_CARD.md` / `docs/M8.9_IDENTITY_INCIDENT_RUNBOOK.md`  
2. **Investigate second** — reconcile, merge detect, metrics, logs  
3. Do **not** delete customers, mass-unlink, or fuzzy-merge in emergency
