# M8.8 — Phase Runbook (Customer Read Rollout)

**Status:** Ops package live — flags remain **OFF** until operators enable them  
**Never skip phases. Phase 4 required before Phase 5.**  
**After Phase 6 (or if remaining Case-primary):** follow steady-state governance — `docs/M8.9_IDENTITY_GOVERNANCE.md` · `docs/M8.9_OPERATIONS_CADENCE.md` · incidents `docs/M8.9_IDENTITY_INCIDENT_RUNBOOK.md`

Related: `docs/M8.8_GO_NO_GO_CHECKLIST.md` · `docs/M8.8_ROLLBACK_CARD.md` · `docs/M8.8_ROLLOUT_ENABLEMENT_PLAN.md`

---

## Fixed sequence

```text
Phase 0  all OFF
Phase 1  CUSTOMER_DOMAIN_ENABLED
Phase 2  CUSTOMER_DOMAIN_DUAL_WRITE
Phase 3  CUSTOMER_DOMAIN_READ_LINE_SHADOW
Phase 4  CUSTOMER_DOMAIN_READ_LINE
Phase 5  CUSTOMER_DOMAIN_READ_NOTIFY_SHADOW
Phase 6  CUSTOMER_DOMAIN_READ_NOTIFY
```

`MERGE_ENABLED` is independent and stays OFF unless a separate merge ticket requires it.

## Phase 0 — Baseline (all flags OFF)

| | |
|--|--|
| **Flags** | All `CUSTOMER_DOMAIN_*` = false |
| **Steps** | 1) Run fixture tests 2) `reconcile scan` 3) Archive summary 4) Confirm health shows flags OFF |
| **Success** | Tests green; scan archived; Case-only LINE OA + Case-only notify |
| **Monitor** | Reconcile counters; Case path error rates |
| **Rollback** | N/A |
| **Hold** | Complete before Phase 1 |

## Phase 1 — ENABLED

| | |
|--|--|
| **Set** | `CUSTOMER_DOMAIN_ENABLED=true` |
| **Steps** | Deploy/restart → health/readiness → confirm Customers DB `ready` → watch config warnings |
| **Success** | App healthy; no unexpected Customer calls on hot paths while other flags OFF |
| **Monitor** | Ops `customerDomain`; startup warnings |
| **Rollback** | `CUSTOMER_DOMAIN_ENABLED=false` |
| **Hold** | Staging ≥ **24h**; Prod ≥ **24h** |

---

## Phase 2 — DUAL_WRITE

| | |
|--|--|
| **Requires** | Phase 1 stable |
| **Set** | `CUSTOMER_DOMAIN_DUAL_WRITE=true` |
| **Steps** | Enable → exercise createCase + linkLineUser → confirm Case never blocked → watch dual-write statuses |
| **Success** | Dual-write success ≥ **99%** over soak; Case create/link OK |
| **Monitor** | Dual-write results; new Cases gaining Customer links; reconcile `missingCustomerLink` trend |
| **Rollback** | `CUSTOMER_DOMAIN_DUAL_WRITE=false` (ENABLED may stay) |
| **Hold** | Staging ≥ **48h**; Prod ≥ **72h** before Phase 3 |

---

## Phase 3 — READ_LINE_SHADOW

| | |
|--|--|
| **Requires** | Phase 2 soak done; reconcile gates green; **no unticketed `lineDiverge`** |
| **Set** | `CUSTOMER_DOMAIN_READ_LINE_SHADOW=true` (`READ_LINE` still false) |
| **Steps** | Enable → OA history/latest traffic → dump LINE metrics / read logs |
| **Success** | ≥ **200** lookups **or** ≥ **7 days** (if low volume); min **48h**; mismatch **&lt; 1%**; conflicts **0** unexplained |
| **Monitor** | `customerHits`, `mismatches`, `conflicts`, `errors`; replies still Case-authoritative |
| **Rollback** | `CUSTOMER_DOMAIN_READ_LINE_SHADOW=false` |
| **Hold** | Until volume **and** time gates met |

---

## Phase 4 — READ_LINE (primary)

| | |
|--|--|
| **Requires** | Phase 3 gates passed |
| **Set** | `CUSTOMER_DOMAIN_READ_LINE=true` (shadow ignored while primary on) |
| **Steps** | Enable → verify view_latest / history → confirm Case fallback on miss/conflict/error |
| **Success** | UX parity; post-fallback mismatch **&lt; 0.5%**; fallbacks explained |
| **Monitor** | LINE metrics; customer-care reports of missing history |
| **Rollback** | `CUSTOMER_DOMAIN_READ_LINE=false` → immediate Case-only OA reads |
| **Hold** | ≥ **72h** before Phase 5 (**mandatory**; no skip without written waiver) |

---

## Phase 5 — READ_NOTIFY_SHADOW

| | |
|--|--|
| **Requires** | Phase 4 soak done (or signed waiver) |
| **Set** | `CUSTOMER_DOMAIN_READ_NOTIFY_SHADOW=true` (`READ_NOTIFY` still false) |
| **Steps** | Enable → result send / close notify traffic → dump notify metrics |
| **Success** | ≥ **100** resolves **or** ≥ **7 days**; min **48h**; mismatch **&lt; 1%**; **0** wrong-recipient incidents |
| **Monitor** | `mismatches`, `caseFallbacks`, `errors`; Case `sent`/`failed` rates unchanged vs baseline |
| **Rollback** | `CUSTOMER_DOMAIN_READ_NOTIFY_SHADOW=false` |
| **Hold** | Until volume **and** time gates met |

---

## Phase 6 — READ_NOTIFY (primary)

| | |
|--|--|
| **Requires** | Phase 5 gates passed |
| **Set** | `CUSTOMER_DOMAIN_READ_NOTIFY=true` |
| **Steps** | Enable → send result flows → confirm Case wins on LINE diverge; payload unchanged |
| **Success** | Send success ≥ baseline; diverge → Case destination; no payload/API contract change |
| **Monitor** | Notify metrics; `[line_close_notify]`; notification lifecycle still on Case |
| **Rollback** | `CUSTOMER_DOMAIN_READ_NOTIFY=false` immediately on wrong-recipient suspicion or send spike |
| **Hold** | Ongoing; **retain Case LINE fields** indefinitely |
