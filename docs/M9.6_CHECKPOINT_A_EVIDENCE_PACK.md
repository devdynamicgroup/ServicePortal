## Purpose

Evidence package required **before** Operator + Reviewer + On-call sign Checkpoint A.

This document does **not**:

- enable `CARE_LIFECYCLE_ENABLED` or `CARE_LIFECYCLE_SEND`

- modify Case notification state

1. Run dry-run scans and archive under `tmp/care-lifecycle/`
