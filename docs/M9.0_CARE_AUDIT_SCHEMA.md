# M9.0 — Care Audit Schema (Notion)

**Status:** Optional durable store — file audit in `tmp/care-lifecycle/` always works.

Env: `NOTION_CARE_AUDITS_DATABASE_ID`

## CareAuditEvent properties

| Field | Suggested Notion name | Type |
|-------|----------------------|------|
| id | Audit ID | title or rich_text |
| caseId | Case ID | rich_text |
| customerId | Customer ID | rich_text |
| eventType | Event Type | rich_text / select |
| scheduledAt | Scheduled At | date |
| triggerSource | Trigger Source | rich_text |
| destinationType | Destination Type | select (`case_line`, `customer_line`) |
| destinationIdHash | Destination Id Hash | rich_text |
| status | Status | select (`planned`, `dry_run`, `skipped`, `sending`, `sent`, `failed`) |
| idempotencyKey | Idempotency Key | rich_text |
| templateVersion | Template Version | rich_text |
| createdAt | Created At | date |
| sentAt | Sent At | date |
| failureReason | Failure Reason | rich_text |

M9.0 write path records to **local files** by default. Notion create is best-effort when DB id is set (future sync script can ensure schema).

**Never** map these onto Case `Notification Status` / `Result Sent At`.
