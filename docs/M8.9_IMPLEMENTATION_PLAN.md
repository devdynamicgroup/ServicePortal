## Required content (must lock in docs)

### Ownership

**Case owns:** Booking, Workflow, Offer, Feedback, Report, Notification **state**  

**Customer owns:** Canonical identity (name, phone, email, address, LINE identity projection)

### Permanent rules

- Case LINE retained permanently as fallback  
- No fuzzy matching  
- No automatic merge  
- No destructive repair  
- Human-controlled flag changes (M8.8)  
- Notification lifecycle remains Case-owned  

### Operational cadence

| When | What |
|------|------|
| Weekly | Reconcile scan; duplicate detect; drift review |
| Daily during rollout shadow | Shadow metrics; mismatch review |
| Incident | Flag rollback **first** (M8.8 card); investigate second |

### Completion criteria (M8)

Complete when: governance documented; ownership locked; rollback documented; operators have runbooks.

**Not required:** all flags enabled; Case LINE removed; business data migration.
