## Locked operational rules

### Rollout sequence

```text
CARE OFF
  ↓
CARE_LIFECYCLE_ENABLED=true          (SEND still false)
  ↓
dry-run ≥7 days + ≥3 successful scans
  ↓
CARE_LIFECYCLE_SEND=true
  ↓
--limit=10
  ↓
--limit=50
  ↓
uncapped
```

Low-volume environments: dry-run window may be **≥14 days** if 3 scans cannot complete in 7 days with meaningful sample size.

### Permanent rules

- Never skip dry-run before SEND  
- Never write Care state into Case `notificationStatus`  
- Case remains ops SSOT; Customer remains identity only  
- Care Audit stays separate  
- Flag-only rollback  
- `CUSTOMER_DOMAIN_*` independent (not required for Care)  
- First live SEND always graduated limits: **10 → 50 → uncapped**

## Content outlines

### `M9.1_CARE_RUNBOOK.md`

1. Fixed phase sequence + commands  
2. Phase 0 baseline (tests green, flags OFF)  
3. Phase 1 `CARE_LIFECYCLE_ENABLED=true`  
4. Phase 2 dry-run observation (7d / 3 scans; sample review; archive reports)  
5. Phase 3 SEND with `--limit=10` → `50` → uncapped  
6. Phase 4 steady-state pointer to cadence doc  
7. Safety: Case notification untouched; care tone; consent skips  

Commands:

```bash
node scripts/test-care-lifecycle.js
node scripts/check-care-rollout-gates.js
node scripts/run-care-lifecycle.js scan --event=reinspection_6mo --mode=dry-run
node scripts/run-care-lifecycle.js send --event=reinspection_6mo --mode=write --limit=10
```

*(CLI `--limit` already supported by M9.0 `runCareLifecycle`; document it.)*

### `M9.1_GO_NO_GO_CHECKLIST.md`

- Global: tests, on-call, rollback card known  
- Before ENABLED  
- Before SEND: dry-run gates, sample ≥20, false positives 0, notification integrity  
- Limit ladder sign-offs (10 / 50 / uncapped)  

### `M9.1_ROLLBACK_CARD.md`

```text
1. CARE_LIFECYCLE_SEND=false
2. CARE_LIFECYCLE_ENABLED=false
```

Verify result-send + OA history still work; do not delete Care Audit / idempotency index.

### `M9.1_OPERATIONS_CADENCE.md`

- Weekly: scan or limited send review; skip/fail mix  
- Monthly: volume trend; copy/consent  
- Incident: rollback first  

### `check-care-rollout-gates.js` (optional)

Read-only payload:

- CARE flag snapshot  
- Inferred phase  
- Latest `tmp/care-lifecycle/latest.json` counts  
- Warnings (SEND without ENABLED; no latest report)  
- Exit 0 normally; exit 2 if latest report missing when SEND on (optional strict mode)  

Must **never** set environment variables or call LINE send.
